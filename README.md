# MindlyFlow

**Нейросети для фото и видео — прямо в браузере**

MindlyFlow — онлайн-платформа с нейросетями, которая позволяет оживлять фото, менять лица (DeepFake), генерировать изображения и видео по тексту, а также создавать музыку. Всё работает без установки программ.

## Возможности

- **Оживление фото** — превратите любое статичное фото в реалистичное видео с естественными движениями и эмоциями
- **DeepFake (замена лица)** — быстро и реалистично заменяйте лица на фото и видео
- **Генерация фото** — создавайте фотореалистичные изображения по текстовому описанию
- **Генерация видео** — генерируйте видео по текстовому промпту
- **Генерация музыки** — создавайте песни по простому описанию
- **Редактор фото** — редактируйте фото с помощью обычного текста

Всё работает прямо в браузере на компьютере и телефоне. Установка не требуется.

## Почему MindlyFlow?

- Без подписок — платите только за успешные генерации (по токенам)
- Бесплатные токены при регистрации
- Результат за 10–60 секунд
- Готовые шаблоны + свои промпты
- Скачивание без водяных знаков
